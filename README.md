# Tijara POS — downloads

Fast billing and clear accounts for Pakistani shops: supermarts, pharmacies, clothing and general
stores. Tijara POS runs on your shop's own computer and works without internet.

This page only hosts the installers and the app's automatic updates.

## Download

**[Get the latest version →](https://github.com/AhsanRao/tijara-pos-releases/releases/latest)**

Under **Assets**, pick the file for your computer:

| Computer                              | File                                         |
| ------------------------------------- | -------------------------------------------- |
| Windows 10 or 11 (64-bit)             | `Tijara-POS-<version>-win-x64.exe`           |
| Mac with Apple chip (M1, M2, M3, M4…) | `Tijara-POS-<version>-mac-arm64.dmg`         |
| Mac with Intel chip                   | `Tijara-POS-<version>-mac-x64.dmg`           |
| Linux, 64-bit (Ubuntu, Debian, Mint)  | `Tijara-POS-<version>-linux-amd64.deb`       |
| Linux, 64-bit (any distribution)      | `Tijara-POS-<version>-linux-x86_64.AppImage` |

Not sure which Mac you have? Apple menu → **About This Mac**: "Chip" means Apple, "Processor"
means Intel.

## Install

**Windows**

1. Open the downloaded `.exe`.
2. If a blue box says "Windows protected your PC", click **More info**, then **Run anyway**.
3. Follow the installer. Tijara POS opens the setup wizard.

**Mac**

1. Open the `.dmg` and drag **Tijara POS** into **Applications**.
2. Open it. If macOS says it can't verify the app, click **Done**, then go to
   **System Settings → Privacy & Security**, scroll down and click **Open Anyway**.

**Linux**

- `.deb`: double-click it, or run `sudo apt install ./Tijara-POS-<version>-linux-amd64.deb`.
- `.AppImage`: mark it as executable (`chmod +x Tijara-POS-*.AppImage`) and run it.

## What you need

- 4 GB RAM or more, 1 GB free disk space.
- A USB barcode scanner and a 58 or 80 mm receipt printer are optional; set them up in the app.
- No internet for daily selling. Internet is used only for updates and optional extras (cloud
  backup, phone app, FBR).

## Updates

Tijara POS checks this page in the background and installs new versions when you close the app.
Your shop's data is never touched by an update. On Mac, download and install new versions from
here by hand for now.

## Your data

Everything stays on your computer. Uninstalling the app **keeps** your shop data. Backups are made
automatically; see **Settings → Backups** in the app.

## Trial and licence

The app runs for 14 days as a free trial. After that, enter the licence key you receive on
purchase in **Settings → Licence**. Your data stays available either way.

## Help

In the app, open **Settings → Help → Save support file** and send the file to
**raoahsan110@gmail.com**. It contains the app version and log files, never your shop's database,
